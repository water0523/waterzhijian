# 本地模型与 API 改写

在 Markdown 栏选中文字，点击浮动工具栏的「改写」，或打开「写作面板 → 写作 → AI 选区改写」。先生成、比较结果，再点击「应用到原选区」；Ctrl+Z 可一次撤销。生成不会自动替换正文。

## 本地 QwenLocal（默认）

1. 启动你自己的 QwenLocal 助手，服务默认为 `http://127.0.0.1:8765`。模型文件由助手管理，不放进编辑器。
2. 第一次使用，双击本目录的「安装本地连接.cmd」，在提示中填写 QwenLocal 程序目录（包含 app.py 和 static 的目录，不是模型目录）。或者在 PowerShell 中运行：

   ```powershell
   .\install-qwen-bridge.ps1 -QwenLocalPath '你的 QwenLocal 程序目录'
   ```

3. 打开编辑器的「AI 选区改写」，选择「本地 QwenLocal」，点击「测试连接」。无需 API Key；以后只需保持本地助手运行。

安装器只复制 `qwen-rewrite-bridge.html` 到助手的 `static/feishui-rewrite-bridge-v1.html`，不修改 app.py、引擎或模型，不需要重启已加载的服务。更新连接页时重新安装即可；删除该单一文件即可卸载连接页。

该连接页适配本项目所接入的 QwenLocal 专用接口，并非任意本地模型的通用接口。如果你没有这种助手，请使用下方「其他本地模型」。QwenLocal 的原有同源与令牌校验保留；令牌不会传回编辑器，也不写入连接偏好。

改写仅提交选区、前后各最多 250 字上下文和你的要求。独立临时会话禁用工具和深度思考，正常结束后删除，不读取已有聊天。服务意外关闭或删除时其他任务正忙，可能残留本次临时会话，可在助手中手动清理。取消只停止本次已接管的生成，不停止服务中正在进行的其他回答。

4B 模型建议一次选择不超过 4000 字，默认输出上限 2048 tokens，可调至 4096。上下文或输出超限会明确提示，不应用截断结果。复杂长文请分段处理；首次加载模型可能较慢，生成期间可以取消。

## 其他本地模型

选择「其他本地模型 · 兼容 API」，填写提供 OpenAI 兼容接口的本机服务及准确模型名。例如 Ollama 常见地址 `http://127.0.0.1:11434/v1`，LM Studio 常见地址 `http://127.0.0.1:1234/v1`；以自己启动服务的配置为准。没有鉴权时 API Key 可留空。

此方式直接从浏览器调用兼容接口，服务需要允许编辑器所在来源的跨域请求。模型需支持 `/chat/completions` 的非流式调用。测试连接读取 `/models`，不发送文章；某些服务没有模型列表时，测试可能失败，可在核对地址后尝试生成。

## 云端 API

选择「云端 API」，填写 HTTPS 接口地址、模型名和自己的 API Key。默认 DeepSeek，也可以连接其他 OpenAI 兼容服务。支持根地址、`/v1` 或完整 `/chat/completions` 地址，不会自动增加 `/v1`，请按服务实际接口填写。

本地与云端互不自动回退。密钥仅发送给当前明确填写的接口地址，按完整地址分别保存；修改地址不会沿用另一个地址的密钥。默认仅当前页面会话保留，勾选「记住在本机浏览器」才会明文写入浏览器存储；可随时「清除所有已存密钥」。密钥和连接偏好不随文章、版本、ZIP 备份、Word 或 HTML 导出。

## 浏览器与发布

连接方式与参数只保存在各自浏览器，GitHub 发布包不包含个人配置、模型权重、运行令牌或 API Key。其他人使用的是他们自己的本机服务或 API，不会连接到你的电脑。

已在 Chrome、Edge 的离线 HTML 中验证本地连接。在线版连接本机时仍受浏览器的本地网络权限与跨域策略约束；若浏览器阻止，允许该站点访问本地网络，或下载离线 HTML 打开。不要关闭浏览器安全功能。服务未启动或连接页未安装时，编辑器会提示，其他写作功能照常使用。
