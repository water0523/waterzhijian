# 六科试卷示例

在编辑器「示例 → 试卷」打开，或导入本目录对应的 Markdown。每科均含原创题型节选、参考答案（中文宋体）与解析（中文楷体），英文默认 Times New Roman；语文引用少量公共领域古诗文。

- [语文](语文.md)：阅读、古诗文、语言运用与作文。
- [数学](数学.md)：选择、填空、向量、含参方程与概率。
- [物理](物理.md)：选择、实验与计算。
- [地理](地理.md)：材料组题、数据表与综合分析。
- [英语](英语.md)：文字听力示例、阅读、语言运用与写作。
- [生物](生物.md)：选择、酶实验、遗传与光合作用。

详细语法、字体和输出说明见 [试卷模板使用说明](../试卷模板使用说明.md)。示例不含插图，不构成完整正式试卷。
