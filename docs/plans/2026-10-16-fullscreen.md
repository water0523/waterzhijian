# 全屏展开

在预览顶部「对照 / 预览」旁增加全屏按钮，使用浏览器原生全屏展开整个编辑器。原有对照、预览布局和排版偏好不变。按钮随真实全屏状态切换图标、文字和无障碍标签；再次点击或按 Esc 退出。根页面进入全屏，保证弹窗、选区工具、导出等功能继续可用。

全屏切换后重新测量编辑区并更新同步滚动定位，不修改文章、撤销历史或保存全屏偏好。不支持或拒绝全屏时提供简短的 F11 提示，按钮保持正确状态。验证电脑 Chrome / Edge 的进入、退出、外部退出、日夜模式、两种布局、弹窗和拒绝保护。

完成：Chrome / Edge 专项各 5 组通过；实际进入和退出、Esc、弹窗内 Esc 优先关闭、外部全屏退出事件、日夜布局与失败恢复均已验证。
