# 长文大纲导航 Implementation Plan

**Goal:** 大纲反映真实标题，折叠不串章，键盘浏览与编辑位置定位适合长文写作。

**Evidence:** 改动前隔离浏览器中，折叠“甲”后在最前面插入 H1，其他全部章节被错误折叠到“主标题”下。旧标题标签还混入 SCIENCE / EVERYDAY、01 等主题装饰。报告保留在 test-results/outline-before，含原构建哈希。

**Architecture:** 使用现有 Markdown 解析器提取带源码位置的真实 heading_open，缓存当前文本的大纲。新独立 outline 模块复用 #persistent-outline、data-jump 和 data-fold；折叠以源码位置和标题签名保存，通过 CodeMirror 精确变更映射。读取偏好严格检查，兼容旧索引记录；整段标题删除取消该项折叠。

**Alternatives:** 继续只修数组索引无法可靠覆盖插入；改成标题文本键会串到重名标题；采用位置映射加重开校验。结构改写与章节拖拽本轮不扩展，避免导航操作改变正文。

### 实现
- src/render.ts：导出 articleOutline，支持 H1–H6、Setext、嵌套真实标题，排除代码、公式和主题生成装饰，标签只提取可读文字。解析不加载公式/导出引擎。
- 新 src/writing-outline.ts：可搜索、章节计数、展开全部/收起下级、跟随定位；按源码正确跳转，打开折叠的预览容器。当前章节按编辑器位置或用户预览滚动更新，输入不反复替换未变化的标题 DOM。
- 键盘上下/Home/End 浏览，左右折叠和进入父子，Enter 定位；搜索有值时 Esc 清空，不误关闭面板；输入法组合期间不抢键。
- 折叠通过编辑器文档变更映射，刷新保存；损坏偏好不崩溃，切稿互不串用。隐藏大纲时不重建标题 DOM，布局显示时刷新；设置跟随开关单独保存，不进入文章/导出。
- src/writing-desk.ts/app.ts 仅接入，不改预设/来源检查/素材/发布功能。

### 验证和交付
- 真实离线 Chrome/Edge：插入标题前缀、标题重名、正文编辑、撤销/重做、删除标题、切稿与重开；源码 H1–H6/Setext/代码/公式/组件与装饰分离；搜索、叶子按钮、键盘、预览容器、关闭同步滚动时当前编辑章、跟随开关、焦点与滚动保持。
- 三套界面日夜、窄窗、400 章节；正文不变、只导航不计写作字数、复制不带大纲 UI。输入法只声明合成事件保护。
- 旧大纲/工作台检查、全部登记回归、类型与发布一致性检查后推送，继续目标；不动用户素材或下载助手目录。

界面检查记录：现有 writing-desk 动态样式晚于 productivity.css 注入，覆盖了停靠模式隐藏大纲内标题的规则；原截图能看到写作面板外标题和大纲内标题两个关闭入口。本批使用明确作用域恢复隐藏内标题，并将搜索框接入日夜界面配色；保留旧 DOM 兼容入口。

完整检查补充复现：窄抽屉 Alt+1 后立刻恢复宽窗口，set() 排队的自动 focus 仍会在下一帧执行。结果 Ctrl+A 选中整个页面，后续输入没有进入编辑器。修正布局刷新取消待执行焦点任务，回调再核对窗口宽度/面板可见性/模态框/用户已选焦点；此处修改影响布局公共路径，需按最终构建重新跑整套回归。
