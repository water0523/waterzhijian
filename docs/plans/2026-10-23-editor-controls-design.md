# 第八轮：编辑器工具与展开菜单的可读性

用户已恢复持续优化，直到下次明确暂停。继续沿用离线架构和三套界面，不修改用户原文、文章主题或六套代码配色的语法颜色。

离线实测 3 套界面 × 日夜 × 6 套编辑器配色：常规 Dark+ 工具栏可读，原截图的极低对比并非稳定复现。发现稳定问题是默认天蓝界面的「插入 / 更多」展开面板使用界面背景，却继承编辑器文字颜色。日间配深色编辑器会浅底浅字；夜间配浅色编辑器会深底深字。Solarized 的工具栏小字与底色对比约 3.64，鼠标悬停的强调色及标题/底栏说明也需复核。

可选方案：强制代码配色跟随日夜会限制既有偏好；所有菜单强制跟随编辑器则破坏已统一的工具菜单外观。本轮采用独立配色职责：编辑区工具、标题和状态跟随编辑器的控件颜色；展开菜单、选中状态跟随界面颜色。为 Solarized/Monokai 增加必要的控件文字/强调色覆盖，不更改正文、语法高亮或导出。键盘焦点使用相应区域的清晰轮廓。

验收：真实离线程序覆盖全部 36 组合及 72 组菜单场景，直接按钮、标题/状态、菜单内文字、悬停和键盘 focus-visible；实际展开/关闭两类菜单、键盘 Esc 焦点回归、保留样式选区及格式刷状态、菜单动作与一次撤销。对比度按最终合成背景计算，区分禁用控件。日夜和皮肤切换、重开后代码配色保持，文章内容与排版快照不变。再做既有综合回归、重新构建一致性、发布包检查并推送。

补充复现：真实重开 Solarized 时，按钮继承的 color 仍在从默认浅字渐变，而工具栏底色已换成浅色。Chrome/Edge 分别观测到约 1.41/1.56 的瞬时文字对比。控件的文字和底色必须一起切换，因此只保留这些控件的按压/阴影动画，取消颜色渐变；增加切换当帧和重开初始化时的读取检查，不用延时等待掩盖问题。
