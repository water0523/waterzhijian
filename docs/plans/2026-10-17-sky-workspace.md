# 天空写作界面调整

## 目标

参考用户提供的桌面界面图：天空融入顶栏，文档、主题、编辑和预览面板共享边界与留白，魔法元素位于外围。三套界面使用同一布局，默认仍为天蓝，装饰依次增加。

## 实现

- 移除占用写作高度的第二条横幅；天空和城堡进入原有顶栏，沉浸模式外围增加云层、书籍、帽子与细金色星轨。
- 统一三套面板的圆角、内边距、工具栏和侧栏层级。默认版保留纯净天蓝；轻装版采用淡紫与少量天空；沉浸版使用完整天空画面和角落插画。
- 使用真实 HTML 控件，原有名称、快捷键和行为不变。素材不遮挡点击，不进入正文、复制或导出。
- 新天空、帽子由内置生图工具制作，既有角色素材保留。全部内嵌、按当前界面与可见区域延迟解码，默认版不读取插画。
- 日夜模式各自调整背景遮罩、文字对比和面板不透明度。编辑器自身配色与文章主题保持独立。

## 验证

- Chrome、Edge 电脑端 1800×1100、1280×800、1024×720；同时打开文章库与主题库，检查可用编辑空间、水平溢出与关键按钮。
- 三套外观、日夜切换、重开恢复、键盘设置、缺失插画回退。
- 文章与正文样式不变，预览选区修改、格式查找、复制与独立 HTML 导出正常；无网络依赖。
- 类型检查、离线构建、发布包与校验值同步，完成后推送。
