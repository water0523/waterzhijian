# 湖南高考试卷主题 Implementation Plan

**Goal:** 新增「试卷」分类及语文、数学、物理、地理、英语、生物六套黑白试卷主题，配原创题型示例、可预览组件和格式改写提示词。

**Architecture:** 共用试卷容器解析与印刷样式，六科分别配置字体角色与示例。沿用现有主题、文章保存和导出流程；选项使用无边框表格，保证复制后保持列布局。原文题号与公式不重写。

**Tech Stack:** TypeScript、markdown-it、MathJax、现有离线打包与 Playwright 桌面验收。

---

### 1. 版式与内容

- 新增 `src/exam-themes.ts`、`src/exam-blocks.ts`、`src/exam-design.ts`、`src/exam-samples.ts`。
- 纸白墨黑、居中卷头、黑体科目 / 题型标题；正文采用宋体，西文 Times New Roman，语文材料楷体，公式保持数学字形。字体为参照试卷的设计选择，不宣称官方发布了统一字体参数。
- 支持卷头信息、考生信息、注意事项、阅读材料、题目、1 / 2 / 4 列选项、答题留白、参考答案与手动分页。参数只接受已知数字，不允许任意 HTML / CSS。
- 六科原创节选分别展示阅读 / 古诗文 / 作文、选择 / 填空 / 解答、单选 / 多选 / 实验 / 计算、材料组题 / 数据表 / 综合题、文字听力示例 / 阅读 / 语言运用 / 写作、选择 / 不定项 / 实验 / 遗传题。无插图、音频或远程资源。
- 后续确认：参考答案独立使用宋体，解析独立使用楷体；包括标题在内的所有普通西文默认 Times New Roman。六科示例分别提供两个容器；数学采用导数等常见高中内容，不采用积分题。

### 2. 集成

- 修改主题分类、主题库与搜索、完整预览、主题导入预览、示例入口、工具栏试卷元素及格式改写配置。
- 新增 A4 宽度选项；打开试卷示例采用宽幅预览。悬停预览不修改文章、主题或宽度。
- 公式自动编号沿用文章开关，不给试题公式额外加题号；普通 Markdown 题号不变。
- Word 保留题目、公式、选项、空白与分页；主题 PDF 使用试卷样式并避免拆开短题目。其他主题导出保持原行为。

### 3. 验证与交付

- Chrome / Edge 桌面离线核对六科：分类、题目与答案、字体、公式、无溢出、组件预览 / 插入、原文保留提示词、保存重开和备份恢复。
- 实际检查 HTML、富文本复制、Word、主题 PDF 和长图；回归公式编号与现有主题 / 提示词。
- 导出六篇可复用 Markdown 到 `试卷示例/`，新增 `试卷模板使用说明.md`（含研究来源与版式边界），更新发行文件、校验、提交与推送。
