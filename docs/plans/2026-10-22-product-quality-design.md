# 持续产品化优化

目标保持完整：持续检查 UI、功能、数据安全与性能，每轮完成验证和推送后继续，不将单轮交付视为整个目标完成。

## 第一轮：命令导航可靠性

代码证据：命令面板强制截取前 70 条；最近记录未检查 JSON 类型；Enter 不检查 IME；执行失败缺少反馈；每次方向键都重新获取命令。

方案：打开时获取命令快照，多关键词匹配与标题优先；按分类筛选；每批显示 70 条，显示更多及键盘跨批浏览；修复输入法、焦点回归和失败反馈。保留原命令 ID、快捷键和三套主题。

验收：超过 70 条仍可浏览最后一条、多关键词与分类共同过滤、组合输入不执行、损坏历史不报错、失败不进入最近记录、关闭返回原焦点。双浏览器离线检查、当前构建验收与发布包哈希核对后推送。

## 后续审查队列

- 长文编辑及预览的定位与响应，公式和组件补全的可发现性。
- 图片出现位置独立设置及版本管理筛选，对照已有补充审查计划逐项核验。
- 检查各操作的取消、恢复和错误反馈，并用实际复现决定改造顺序。
- 已复现的下一轮问题：独立浏览器将 writing-log 偏好设为合法 JSON `null` 后，统计更新抛出 `Cannot convert undefined or null to object`。检查历史数据的类型校验及统计口径，修复不得清除文章内容或手动版本。

## 第二轮：沉浸旅途侧栏插画

用户截图中的角色区域只剩背景和文字。已在冷启动时关闭文章库的独立浏览器复现：进入沉浸旅途后再打开文章库，角色 img 没有 src。根因是皮肤加载器按当前可见性筛选，隐藏图片之后没有补加载入口。

选择在启用魔女界面时准备其全部图片节点，共用已有图集加载缓存。比新增可见性观察器更直接，也覆盖轻装到沉浸、隐藏面板与专注模式恢复等路径。默认天蓝界面仍不主动加载插画。不改素材、图集裁切和装饰尺寸。

验收覆盖：关闭侧栏的冷启动、轻装切沉浸时侧栏隐藏、日夜模式、1600/1280/1100 窗口、保存刷新与侧栏重开；角色图片真实解码且裁切区域非零。默认启动无插画 src，全部离线无报错，双浏览器检查及发布包验证后推送。统计问题保留在后续队列。

## 第三轮：公式补全、快捷键与汉字

按用户新增要求扩充反斜杠触发的公式补全，保留代码与真实 MathJax SVG 两列；不显示候选名称或分类说明。共 278 个唯一候选，包含新数学命令及展开为受支持 LaTeX 的物理片段。复用现有离线公式引擎及缓存，仅候选显示后渲染；不引入在线字体或新公式引擎。

默认 Ctrl+M、Ctrl+Alt+M 分别插入空的行内和行间公式，光标置于中间，有选区则包住选区。保留浏览器友好方案之前的 Ctrl+Alt+F 兼容入口，自定义配置优先。直接汉字、text 注释和中文下标保留，SVG 内显式设置中文字体回退，标准数学字形保持 MathJax 输出。

验收包括所有候选实际渲染、重复命令检查、分式字段与 Tab 切换、物理片段、希腊字母、别名、输入不自动改文、代码边界、补全开关、日夜及三套界面。快捷键通过紧接着输入文字核实光标位置；检查中文 SVG 字形宽度和独立 HTML 导出的文字与字体。将已有公式补全检查纳入发布登记，完成双浏览器验证再推送。
