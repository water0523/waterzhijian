# Workbench Refinement Implementation Plan

**Goal:** 按用户参考图整理浅蓝工作台，文章名称始终来自首个顶层 H1，取消自定义改名。

**Architecture:** 保留现有离线存储和文章渲染。页首改为只读文章标题与保存时间，统一日夜 / 本地 / 预览 / 导出控件；文章导航和统计复用现有文章库数据；预览区保留对照、阅读、宽度、全屏和编辑功能。旧 titleMode 字段只用于读取历史文件，进入当前工作台后统一按 H1 派生标题，没有 H1 时显示未命名文章。

**Tech Stack:** TypeScript、CodeMirror、原生 DOM / CSS、Playwright、现有离线构建。

### Task 1: H1 唯一命名来源

- 修改 `src/app.ts`、`src/model.ts` 和 `index.template.html`，去掉改名输入与模式开关，首个有效 H1 自动更新标题；保留旧数据格式兼容。
- 增加专项测试，覆盖修改 / 删除 / 撤销 H1、富文本标题、代码与引用、旧 manual 文章导入与重新打开、备份和恢复。

### Task 2: 整理界面

- 新增统一 SVG 图标与工作台样式；整理顶栏按钮、只读标题及自动保存时间。
- 左侧显示新建、全部文档、最近编辑、回收站、分类、文章列表和真实写作统计；保留现有文件夹与文章操作。
- 预览头分成布局 / 全屏与正文宽度 / 编辑工具两行，提供窄幅、宽幅图标，状态与下拉框同步。
- 适配日夜配色与 1024–1600 像素电脑窗口，保留文章主题、主题悬停与原图标。

### Task 3: 验证和交付

- 运行类型检查、H1 和工作台专项、现有核心与全屏检查；调整已不适用的改名测试。
- 查看日夜截图，验证导出 / 备份 / 旧稿恢复及窄电脑窗口。
- 更新说明、离线 HTML、Pages 构建、源码包及校验文件，保留旧名入口。

### Task 4: 公式命令补全（追加需求）

- 本地候选覆盖希腊字母、分式、根号、求和、积分、函数和常见关系符号。
- 反斜杠前缀触发，方向键选择，Enter / Tab 插入；结构片段可用 Tab 逐项填写。
- 写作助手提供默认开启的持久化开关；代码区域、转义反斜杠不触发。
- 验证键盘 / 鼠标、占位填充、开关与重新打开文章、日夜颜色、实际公式渲染。

### 完成记录

- H1 唯一命名、顶栏与文档侧栏、预览工具整理、日夜默认编辑配色已落地；旧稿 / 恢复点数据结构保留兼容。
- 公式候选使用本地 CodeMirror 补全源，不联网；数学结构使用可填写片段，命令说明为中文，提供持久化开关。
- 两款电脑浏览器完成工作台 8 组、公式补全 7 组、核心 27 组、H1 / 加粗 12 组、全屏 5 组、存储 17 组检查。说明与源码包同步更新。
- 追加右上角 GitHub / 哔哩哔哩入口：使用本地 SVG 图标与新标签页链接，沿用日夜配色；两款浏览器各 5 项跳转 / 布局检查与工作台回归通过。
