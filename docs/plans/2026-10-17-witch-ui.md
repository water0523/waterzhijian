# 魔女之旅界面 Implementation Plan

**Goal:** 保留默认天蓝界面，在界面设置中新增「魔女之旅 · 轻装写作」和「魔女之旅 · 沉浸旅途」两种可持久保存的外观。

**Architecture:** 界面外观是独立的本机偏好，不修改文章、文章主题、Markdown、排版设置、编辑器配色或导出内容。通过根节点属性与独立样式层切换。使用用户提供的透明图集，CSS 裁切视窗取用角色、城堡、书本、羽毛笔、罗盘与导航图标；原始像素不做改绘。图集放入离线资源区，仅打开界面设置或启用魔女界面时读取和解码。

**Tech Stack:** TypeScript、CSS、现有单文件构建与离线图片注册机制、Playwright（Chrome / Edge 桌面）。

## Task 1: 素材检查与资产
- 核对四张素材的尺寸、透明通道、有效画面及低透明度底色；记录选择与裁切坐标。
- 使用 `assets/witch/elaina-atlas.png`，保留用户原文件。按单图集视窗取元素，避免重复嵌入大图或把生成文字变成真正按钮。
- `build.mjs`、`src/assets.d.ts` 支持独立 PNG 离线载荷，默认界面不解码图集。

## Task 2: 独立界面设置
- 新建 `src/ui-skin.ts`，提供默认天蓝、轻装写作、沉浸旅途三项选择；新增右上角「界面设置」入口，键盘可操作，选择即应用。
- 偏好仅保存 `paper-ui-skin`；未知值回退天蓝。载入失败保留可用配色并提示，不能影响写作。
- 初始化恢复已选外观；不调用文章修改、文章主题切换或重新生成正文。

## Task 3: 两种氛围与夜间
- 新建 `src/ui-skin.css`，月紫、奶油纸、香槟金，保持原有按钮名称、布局及阅读清晰度。
- 轻装：窄幅城堡横条、图标与书本小物；沉浸：更宽横幅、角色、侧栏插画、羽毛笔与星象装饰。
- 独立夜间配色、清晰焦点、无障碍隐藏装饰、装饰不接管鼠标事件，尊重减少动态偏好。文章本身不染色、不插入人物。

## Task 4: 桌面验证与交付
- 默认不变、两种外观、日夜、保存重开、未知偏好、安全回退；检查 1800 / 1280 / 1024 桌面可用空间与溢出。
- 核对文章数据、主题、正文视觉、编辑器配色、公式与导出未受外观选择影响；实际编辑、格式修改、复制、HTML 与备份。
- 类型检查与构建；更新使用说明、源码包与校验和，保留用户原素材与下载助手解压目录，完成后推送。
