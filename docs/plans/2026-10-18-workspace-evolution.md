# 工作台整合与写作连续性优化

本计划承接标题编辑、标点加粗、立体帽饰；不撤销自动版本清理、手动版本和用户原稿。仅电脑 Chrome / Edge。逐项实做和验证，不把建议原文里的旧行号或测试数字当成本次事实。

## 实施清单

- [x] 左上手动文章名、自动 H1 回退、保存/历史/导入/撤销；普通中文标点加粗用原生 Markdown；生成透明立体帽饰（专项初验通过）。
- [x] P0 连续位置：增量恢复正文、选区/滚动/预览锚点；CM 与预览路由统一；键入自然分组；LRU 会话上限。
- [x] P0 编辑保护：轻量主题试看、防抖/取消、暂停抢选区；样式更新不重建正文；滑块 rAF 试改与一次提交。
- [x] P0 问题清单：去重、统一计数/定位/复制提醒；普通本地图片不拦复制。
- [x] P0 面板与模式：关闭来源检查真正取消；统一布局管理、桌面断点、抽屉遮罩/inert/焦点恢复、排版停靠与适应宽度。
- [x] P1 统一写作面板：大纲/写作/排版/素材/发布/设置六 tab，状态保留与 Alt+1…6；减少浮层重复入口。
- [x] P1 工具栏四组、统一图标/点击区；插入与更多；格式改写归发布；动效三档与 reduced-motion。
- [x] 命令面板：搜索文章/主题/插入/导出/设置/快捷键，最近五项，键盘导航。
- [x] 专注/打字机/段落聚焦/计时；Esc 与按钮退出，恢复布局。
- [x] 斜杠菜单：仅普通段落行首或空白处，避开代码/公式；可关闭。
- [x] 微调器与预设：显式覆盖来源、分项重置、主题装饰/纹理、差异预览。
- [x] 本次写作/日周增量统计，区分文章总字数与净增/输入累计。
- [x] 安全同级章节拖拽，复杂组件/代码围栏完整边界保护，一次撤销。
- [x] 金句/封面工坊：主题配色、署名、可选本地二维码，导出 PNG / 插入素材。
- [x] 智能 HTML 粘贴：白名单转 Markdown，先预览差异与纯文回退。
- [x] 文章拆分/合并：原稿保留、素材/贴纸/历史迁移、合法边界与独立 ID。
- [x] 新手三步引导（仅新用户、可跳过）及可搜索快捷键帮助。
- [x] 主题浏览惰性载入、至多三主题对比、轻/整篇试看、策略显式可见。
- [x] keyed 列表和保存反馈、可操作 toast、重操作进度与取消。
- [x] 当前源码/产物/哈希/三类发布包同步；双浏览器组合回归、截图、提交推送。

## 验证原则

测试先验证初始化与无脚本错误；覆盖长文第 400 行附近连续撤销/重做、预览改字焦点、1280/1440/1920 面板组合、键盘焦点与 Esc、旧稿/ZIP、关闭检查模式、命令/斜杠不误插入、拆分合并不丢素材，保留人工平台草稿与原生输入法为未执行项。已有报告只对其对应哈希有效。

实施边界：小于 1200 的电脑窗口使用抽屉；更宽窗口按编辑空间主动收起其他栏。章节拖拽只开放普通单 H1 的二级章节，组件 / 多 H1 关闭；不同素材外观及重复脚注定义的合并显式拒绝。统计说明净增为源码非空白字符，不冒充文章总字数。

用户补充：两套伊蕾娜界面均适配新功能的淡紫 / 月夜面板、菜单、命令面板、专注状态和动效；新添 workspace-skins 专项逐套核验，默认天蓝保持独立。
