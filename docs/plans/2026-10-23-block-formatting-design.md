# 区块格式与列表结构保护 Implementation Plan

**Goal:** 标题、正文、引用、诗歌与列表快捷键保留原文和 Markdown 结构，转换可一次撤销。

**Evidence:** 改前隔离离线页面中，Ctrl+Alt+2 将三行代码围栏及 $$ 公式逐行加上 ##；Setext 的 --- 也被改成 ## ---；引用内列表变成 1. > 文字。test-results/block-before/report.json 保留实际输入、输出及产物哈希。

**Architecture:** 复用渲染器的 Markdown 区块解析，新增纯函数 block-format-plan.ts 返回源码增量与明确拒绝原因。标题/引用/诗歌和有序/无序列表统一使用计划，编辑器只提交一次格式事务。保留原文 inline 标记，不重新序列化全文。

备选方案：继续扩展逐行正则无法区分代码/公式/下划线标题；直接重新生成 Markdown 会改写无关源码。采用解析识别边界 + 局部增量。禁止把失败的转换默默降级为只修改一部分选区。

### 实现行为
- 标题与正文保留引用/列表容器；单行 Setext 标题连同下划线整体转换，正文转换去除格式用闭合 #；同级重复应用不改正文、不生成撤销记录。多行 Setext 转单行 ATX/列表会明确提示先整理，不自动合并原文行。
- 代码、缩进代码、公式、表格、分割线、诗歌/组图内容、引用定义及组件边界拒绝转换。组件内部普通段落仍可转换；选区跨受保护区域时整个操作拒绝。
- 引用增减一层并保留缩进；空行可插入引用标记；诗歌整段切换保留内容，局部诗行不被当成普通段落改写。
- 列表在引用内部转换，按每层/每组计数；保留任务勾选与内联格式。列表项续行/子项按标记宽度变化调整缩进。显式选择不完整列表项时提示选全；未选中时按当前完整列表项处理。取消列表时只移除所操作项的标记和对应缩进。
- 标题 H4–H6 在按钮菜单也可选；按钮/快捷键同一路径、无效操作反馈清楚，预览改字结构锁定时拒绝结构转换。
- 无正文的 ATX 标题也识别为空标题，取消时不留下 #；列表内部嵌套引用暂不做标题 / 列表转换，明确拒绝，防止把引用标记吞入正文。
- 列表内部嵌套诗歌不直接解包，避免移除外层列表标记；引用内整首诗歌解包保留引用容器。
- 无尾随空格的空列表标记（-、+、*、1.、2)）按真实列表识别，切换不把旧标记遗留为正文，添加空标题时保留列表分隔空白。

### 验证
- 纯计划覆盖边界、源码不变、Setext、闭合 #、重复操作、嵌套列表/续行/任务/引用、CRLF 和空选区；明确保留局限，不宣称任意 Markdown 的等价变换。
- Chrome/Edge 实际按钮和快捷键、选区末尾换行不误含下一段、一次撤销/重做、长文位置、公式/代码渲染保护、三套界面日夜、保存重开和预览模式；原有快捷键/跨段格式/查找/大纲回归。
- 类型检查、完整登记回归、确定构建、发布包校验后提交推送；不修改用户素材目录与下载助手目录。持续目标保持，不能以本批完成宣称所有产品优化已完成。
