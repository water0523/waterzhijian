# 代码切换与脚注编辑 Implementation Plan

**Goal:** 代码按钮与快捷键可靠切换，已有脚注可直接定位编辑，新脚注以局部事务插入，保留正文和大纲位置。完成本批验收与推送后按用户要求暂停目标。

**Architecture:** 新增 source-writing-plan.ts 纯源码计划，复用真实 Markdown 区块和行内代码映射。formatting.ts 统一提交增量、选区及一次撤销；editor.ts 在同一事务内接受目标选区。默认单文件架构、现有按钮和快捷键保持。

**Tech Stack:** TypeScript、Markdown-it、CodeMirror、离线 HTML、Playwright Chrome / Edge。

## 改前证据与方案

test-results/code-notes-before/report.json 对应 66b9971 构建：选中完整 `alpha` 代码再次转换产生双层反引号；固定三反引号包住含三反引号的内容时提前闭合；在 [^1] 内插入脚注变为 [^[^2]1]；新增脚注的整篇替换使已折叠的子标题重新展开。

继续叠加包裹正则无法识别已有区块；整篇重新序列化会改动无关原文和映射。采用解析边界 + 局部编辑，代码文本不重新排版。

## Task 1: 纯源码计划与边界

- Create: src/source-writing-plan.ts；Test: tests/source-writing-plan.mjs。
- 行内代码：识别完整代码标记、全部内容或空光标所在的代码；取消只移除格式标记。新代码使用比内容中的反引号更长的分隔符，按 Markdown 规则补边界空格。局部代码选区不默默扩大，提示选择完整代码。
- 代码块：按钮自动识别多行、块快捷键强制独立代码；围栏长度避开内容，保留字节与换行。完整闭合块 / 全部代码行可取消；完整未闭合块补闭合。部分区块及列表内代码结构明确提示源码处理，引用容器保留。缩进代码暂不自动解包。
- 脚注：光标或小选区落在已有标记时，选择注释首行；缺少定义时补同名定义。普通插入使用未占用编号，在选区后加引用、文末加注释，保留原文字节及换行。代码、公式、图片与组件边界内不插入脚注；定义中的操作不再新增引用。
- 先用独立 Markdown 解析器与 ChangeSet 证明分隔符、保护边界、脚注去重、CRLF 和增量位置；实际失败必须修复，不用宽松断言代替。

## Task 2: 实际编辑器接入

- Modify: src/formatting.ts、src/editor.ts、src/markdown-shortcuts.ts、src/app.ts、index.template.html。
- formatTextRanges 接受事务内目标选区及显式定位；仅有跳转不修改正文或历史。按钮 / 快捷键使用同一计划，错误反馈并恢复编辑焦点；预览改字期间结构命令锁定。
- Test: tests/source-writing.mjs 使用真实按钮和快捷键，覆盖生成 / 取消、围栏、一次撤销、脚注已有 / 缺失 / 多行、折叠和选区范围保留、长文定位、保存重开、三套界面日夜。

## Task 3: 交付

- 更新 CHANGELOG.md、使用说明.md、scripts/test-suites.mjs 和验收脚本；保留改前证据。
- 完成当前源代码审阅和专项检查再冻结构建；两次构建字节一致，最终同一构建执行全部登记回归，发布包与哈希交叉核对。
- 只提交项目源码与发布文件，不提交用户素材和解包的下载助手。推送后核对远端提交；调用目标暂停并停止后续优化。
