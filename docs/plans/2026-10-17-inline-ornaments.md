# 新增行内修饰

用户要求在现有「修饰」中增加美观选项。保留直接下拉、实际样式预览和点击应用的交互，新增细框标记、柔彩胶囊、书签侧线、朱砂括线、双线强调。

- 使用单一白名单属性 `ornament=outline|pill|ribbon|bracket|doubleline`，切换时替换同一属性，再点已选项取消。与泥金金句互斥，避免背景和底线相互覆盖。
- 不改原文，可与字体、字号、字色、荧光、着重号等组合。显式字色与荧光优先于修饰预设。
- Markdown 和预览的选择均可操作，沿用跨正文段落、局部重选和单次撤销机制。
- 格式查找新增「修饰样式」，按具体选项过滤、跳转、批量修改和清除。格式改写提示词同步白名单。
- 使用普通 span 内联边框、底色、圆角和留白，复制与 HTML/PDF/图片保留。Word 保留可编辑文字和底色，细框与双线分别映射标准文本边框与双下划线，圆角和左右单边框以兼容格式呈现。
- 验证每个选项的应用、切换、取消、局部重选、跨正文段落、撤销、查找批量处理、富文本复制、HTML 与 Word 导出；保护代码和公式，拒绝非法属性。
