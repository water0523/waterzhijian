# 写作查找与定向修改 Implementation Plan

**Goal:** 在长文中安全修改选中的段落，逐处替换不丢位置，并保护中文输入。

**Architecture:** 复用现有 FindReplace、格式查找与文章撤销事务。选区是文章 ID、CodeMirror Text 引用和源码范围；通过精确文档变更映射边界，切稿或状态整体替换时明确失效，禁止悄悄变为全文替换。格式匹配允许裁剪普通文本，原子映射只允许完整命中。

**Tech Stack:** TypeScript、CodeMirror 6、现有离线构建与 Playwright。

---

备选方向：新增写作目标与计时、扩大文章大纲、改善查找替换。已有日历/成就/专注计时，新增统计入口会重复；大纲已有搜索与跳转。选区限制和逐处替换的定位属于当前明确缺口，先做这一批，不扩展到正则表达式或自动改正文。

### Task 1: 匹配和范围
- 修改 src/find-formats.ts，保留已有调用，增加全词选项和范围参数。全词按 Unicode 字母、数字、组合音标、下划线边界判断，范围不能制造虚假的词边界；中文连续句内建议关闭全词。
- tests/find-formats.mjs 验证英文子串、Unicode/组合字符、特殊符号、真实源码边界、范围端点与局部显式样式。格式匹配不能包含代码/公式，也不能误改范围外的同一格式。

### Task 2: 文档范围和写作面板
- src/editor.ts 增加文档变化观察入口，在业务 onChange 之前通知。它跟随现有编辑器实例，恢复缓存 EditorState 仍可工作。
- src/find-replace.ts 增加仅选区开关、使用当前选区按钮、行号范围说明。开启时未选择/范围失效则零命中并禁用修改；输入/撤销精确映射，整体重置/切稿清空旧范围。关闭窗口释放范围，不写入文章或导出。
- 单行短选区第一次打开查找时带入查询；跨段选区保留原查询。保留全文默认，范围开关同时用于文字和格式。
- 单次替换后选中后续匹配并环回，跳过本次新插入的匹配；同文替换仍前进，全部替换仍一次撤销。Enter 刷新尚在防抖中的查询，组合输入不跳转。Esc 逐层关闭菜单与查找，返回编辑区保留选区。

### Task 3: 实机验收与交付
- 新增 tests/writing-search.mjs 并登记：选区外同字/同格式不变、局部外层样式、输入前缀/选区内增删/撤销、选区删除为空、切稿/同稿状态重置、替换长度变化/删除/自匹配/无变化、输入法合成保护、即时 Enter、长文位置、两个浏览器离线验证。
- 三套界面日夜和窄窗检查；查找 UI 和范围不进入复制/导出。保留旧 find-replace、格式批量操作、选择格式和存储回归。
- 更新使用说明与验收报告，类型检查、完整登记回归、构建与发布包校验后提交并推送。不碰用户素材目录与下载助手展开目录。
