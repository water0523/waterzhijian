# 公式自动编号

- 在「排版设置」加入默认关闭的「公式自动编号」开关，设置随文章、恢复点和备份保存；切换主题保留开关，恢复主题默认设置时关闭。
- 渲染独立公式时使用 MathJax 的编号规则，全文连续计数；保留手写 `\tag`、AMS 环境及跳过编号命令，不写入 Markdown。期刊公式组件隐藏原有自动题签编号，避免重复。
- 实时预览、富文本复制、HTML、图片、主题 / 标准 PDF 和 Word 使用一致的编号；纯 Markdown 导出仍为原始源码。无公式的文章不加载公式引擎。
- 用 Chrome、Edge 的桌面离线流程验证开关、混合公式、保存 / 恢复、备份、导出和原有公式样式；更新说明、打包并推送。
