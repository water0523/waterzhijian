# 文章与主题并列工作区

- 保留原完整主题库 / 管理窗口，在左侧增加文档、主题、回收站图标栏；文章库与主题库可分别开关并并列显示。桌面窄窗口以侧栏浮层保留编辑区宽度。
- 主题侧栏显示真实缩略排版、名称、分类和收藏，支持搜索与分类筛选。悬停或键盘聚焦只试看当前文章，离开恢复正式主题及原来的自定排版；点击才正式应用。
- 试看状态独立于 Article，不改正文、主题字段、排版设置、更新时间、恢复点或备份。切换文章、关闭侧栏、打开窗口、复制 / 导出时清除试看，防止临时样式混入输出。
- 文章库显示标题、字数、更新日期、主题与文件夹，保留历史、移动、副本、删除 / 恢复入口。
- 顶部控件采用清晰紧凑的平面分组，增加对照 / 预览切换。字体等下拉仍保持上一轮的悬停与点击固定交互。
- 验证实际文章的即时试看与移出恢复、点击确认、手动排版恢复、不污染保存 / 备份、切换文章、收藏 / 搜索、侧栏开关、夜间及 1440 / 1280 / 1024 电脑布局。只验证电脑环境，不推送 GitHub。

- 补充：收藏不限数量，兼容旧收藏偏好；收藏内支持拖动、上移 / 下移和筛选后的相对排序，两处主题库共用顺序并跨重开保留。
