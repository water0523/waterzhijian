# 深空靛蓝与松石青翠期刊主题实施计划

**目标：**还原用户提供的六张参考图的排版系统，交付两套可编辑、可复制、可备份的科普期刊主题及示例。

**架构：**保留已验证的离线 MathJax SVG 公式链路，按图还原卡片外观，不将其宣称为 KaTeX。新增安全 Markdown 容器和单行副标题，解析与行号映射共用现有 Markdown-it；主题只负责表现。普通 Word / 知乎展开为标准文档，公众号 / HTML / 长图完整展开推导，所有正文保留。

**技术：**TypeScript、Markdown-it、MathJax SVG、DOMPurify、现有导出与 IndexedDB。字体声明 Noto Serif SC / 思源宋体、Noto Sans SC / 苹方、楷体 / 仿宋、JetBrains Mono 的本机回退链；不动态下载字体。

## 任务与验证

1. `src/journal-blocks.ts`：abstract / theorem / equation / derivation / takeaways / references 六类卡片，`:::subtitle` 单行副标题；正文走原解析器，支持公式、脚注、列表、代码、嵌套，保留绝对行号。闭合标记不误读取代码围栏，不完整块保留原文。通过 `tests/journal-themes.mjs` 的实际预览和源码编辑断言。
2. `src/journal-design.ts`、`src/themes.ts`、`src/theme-design.ts`、`src/model.ts`：两套配色及字体键；正文 15.5px / 1.88 / .04em，衬线标题、浅编号、英文副题、真实导读首字下沉、楷体引文、点阵定律、公式释义、三线表、图注、核心要点与参考文献。375 / 430 / 宽屏截图审阅；文章显式设置优先。
3. `src/render.ts`、`src/documents.ts`：自包含复制保留样式和卡片；推导完整展开，标准输出保留正文结构与所有公式。检查真实剪贴板、独立 HTML、Word 内部段落 / 媒体、备份和重开。
4. `src/app.ts`、`src/workspace.css`：就地插入卡片菜单、Aa 字体标签透视、示例新文章入口。字体标签只属于工作界面，不进统计、复制、长图或导出；日夜与手机下按钮可用。
5. `src/journal-sample.ts`：参考图风格的可操作样例及本地示意插图，保留当前稿；用示例解释公式编号、符号释义、英文副题等写法。
6. 两浏览器针对新功能及现有核心流程检查，扩充主题数量相关验收；更新说明、打包与本地提交，未得到用户指令不推送。
