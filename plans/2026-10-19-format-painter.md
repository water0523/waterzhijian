# 格式刷实现与验证

- 加粗前放置同套 SVG 格式刷，取样后一次划选应用；Esc / 再次点击 / 改文 / 切稿取消。
- 复用文本源映射与局部格式事务，复制一致的局部属性，替换目标旧属性，保护选区外文本和块结构。
- 支持 Markdown 与预览双向取样应用，跨同类正文；拒绝混合样本和受保护结构。
- 检查真实鼠标与键盘选区、替换与普通样本清除、一次撤销重做、取消和切稿、三套界面日夜。
- 更新离线构建、使用说明、当前产物验收和发布包并推送。

## 双击锁定扩展

- 保留单击一次，双击锁定同一份格式并连续应用；避免原生双击的第二次 click 取消样本。
- 区分刷格式自身的变更与手动改文；刷完更新源文快照，手动改文 / 撤销 / 切稿仍取消。
- 状态持续显示锁定及次数；逐处撤销，支持 Esc、单击和取消按钮退出。
- 状态放在现有编辑栏标题内，保持按钮位置和高度不变，防止双击第二下落空。
- 验证预览 / Markdown 连续混合应用、非法选区后继续、一次模式升级锁定及三套界面日夜。
