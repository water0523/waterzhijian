# 山窗听雪 · 古籍文学模板（待科普主题验收后实施）

用户明确顺序：先做完深空靛蓝 / 松石青翠，再做本模板。参考：2026-10-15 提供的五张文学截图与八大组件说明。仅本地开发，不推送。

## 视觉与字体

- 暖纸底、墨黑、朱砂、泥金，细纸纹；Noto Serif SC 700 的 H1/H2，字距 .14–.18em，单鱼尾版心纹。
- 正文 16px / 2.08 / .06em，顶部一键切换书卷宋体、温润楷体、现代人文黑；切换属于文章设置，保存 / 恢复 / 备份。
- 古诗词、尺牍：LXGW WenKai / Kaiti SC 楷体回退；夹批、小序、典故笺注、题画诗：仿宋。字体与标签透视复用科普 Aa 控件，说明设备字体回退，不虚报字体已安装。

## 八大组件清单

1. 线装书刊头：岁次 / 节气 / 物候标尺、虚线订口、总第某辑、作者与书画篆刻署名、清欢小印。
2. 卷首题记：四角回纹折线框、朱砂阴文文心印、仿宋题记与右侧署名。
3. 散文：2.8 倍真实首字下沉、起首阳文印、字下着重圆点、泥金金句划线、右侧竖排眉批。
4. 古诗词双模式：A 中轴对称词笺卡（词牌、仿宋小序、韵脚微标 △）；B vertical-rl 右起竖排乌丝栏卷轴（鱼尾版心、朱丝分栏）。诗词原始换行必须保留。
5. 文言评点：小号朱砂仿宋行间夹批与可收起 / 上下滚动的典故考据抽屉，正文、夹批及脚注清楚分开，预览文字修改保留源码对应。
6. 新诗：阶梯式缩进与留白，左侧浅金行号标尺（01/05/10/12 这类抽样行号），不因主题切换丢换行和缩进。
7. 中国书画装裱三式：单图立轴与竖排题画诗；横向手卷画廊与分段题跋；双联对开册页。支持用户粘贴 / 拖入图片和图片说明，样例使用可离线携带的素材。
8. 文末古籍木记牌记与篆刻藏书票，完整的出处 / 版权 / 印记信息可自行修改。

## 输出原则

公众号若不支持竖排、横向滚动、交互抽屉，不承诺保留原效果；复制 / 导出采用明确的横排全文、纵向图组、全部展开等兼容转换，文字、诗行、夹批、图注、题跋不丢失。高级效果保留在本地预览；标准 Word / 知乎输出维持常规文档。真实公众号粘贴仍需环境验证。

## 验收要求

每个组件的真实文章样例；375 / 430 / 宽屏与日夜；三气质切换持久化；预览编辑准确回写；剪贴板与独立 HTML 全文无裁切，Word 结构 / 图片完整；ZIP 导入和刷新恢复；字体透视不进入正文统计、复制或长图。
