# 选区样式下拉细化

- 按用户最新要求，舍弃样例卡片、分类面板和二次确认。
- 将字体、字号、字色、荧光、半高荧光、修饰、文体拆为独立工具栏入口，各自向下展开。字体、修饰和文体展示真实格式；荧光与半高各 17 色并支持自定，半高使用紧凑色块，按最新要求不再展示笔触示例。
- 点选立即应用，保留选区便于继续叠加；再次选中已启用的修饰即取消。字体、文体、颜色提供跟随正文，修饰提供清除全部。
- 自定字号回车应用、自定颜色在颜色选择器确认后应用；各次操作可独立撤销。
- 保留安全序列化、已设样式回显、原位更新。菜单受桌面视口约束，短窗口滚动列表；无需寻找应用按钮。
- 检查 Chrome / Edge 桌面环境的下拉选择、实际效果、撤销、取消、文体、公式、复制、Word、夜间和缩窗。
