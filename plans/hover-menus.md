# 编辑器悬停菜单与修饰去重

- 鼠标停留 100 ms 自动展开临时菜单，不抢走编辑器焦点，不更改正文。临时菜单只在按钮、菜单本身及两者间的垂直连接通道内保持，移出后 120 ms 收起。
- 点击触发器将临时菜单固定；固定状态移开鼠标不关闭，悬停其他按钮不抢走当前菜单。点击其他按钮可切换，重复点击当前按钮收起。关闭后停在原按钮上不立即重开，离开再移回可重新悬停展开。
- 点击菜单内输入框或用键盘激活时固定；Esc、关闭按钮、外部点击沿用收起行为，保留选区操作状态。鼠标离开浏览器或窗口失焦时，临时菜单收起。
- 应用于字体等七类选区下拉、段落及插入类菜单；无有效文字选区时不在悬停中弹错误，组图不存在时不展开组图设置。不悬停打开主题选择等对话框。
- 两处工具条都直接提供 B / I / U / 波浪线 / 删除线。修饰菜单只保留字下着重号、泥金金句和清除全部样式，不再重复常用格式。
- 桌面 Chrome / Edge 验证临时 / 固定状态转换、上下通道、离开收起、快速切换、直接应用、自定输入、键盘与焦点，回归上次快捷条消失修复、格式与矮窗口位置。
