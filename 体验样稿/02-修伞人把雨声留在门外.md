# 修伞人把雨声留在门外

:::digest-masthead 街巷来信 · 一个普通下午
原创虚构随笔 / 非水·成章体验样稿
:::

:::digest-note 卷首手记
有些地方让人记住，不是因为它有多特别，而是因为你急着赶路时，曾有人请你坐一会儿。
:::

## 那把伞，先别急着扔

雨是在我经过老街口时下起来的。伞骨“咔”的一声向外折去，我站在屋檐下，和一小片倾斜的天空对视。

修伞的老人朝里挪了挪板凳。他没有问伞值多少钱，先用指尖摸过断口，再从抽屉里找出一根短短的金属条。桌边的收音机很轻，像有人在另一间屋子说话。

“能修。”他说，“你先把肩上的水擦一擦。”

我原本准备听见一个价格，或者一句劝我换新的话。[这句不急不慢的“能修”，却先把我的下午接住了。]{marker=#fff29b}

:::digest-quote 留在纸上的一句话
东西坏掉的时候，先看看还能不能接起来。人赶路的时候，也可以先坐下来。

—— 虚构人物的话，写给一个真实的雨天
:::

## 他记得的，是每个人撑伞的姿势

老人说，有人喜欢把伞压得很低，有人走得快，伞面总被风掀起来。他修过的伞没有登记册，倒记得谁每次离开都会把门边的水扫一下。

我问他，修一把旧伞究竟划不划算。他抬头看了看雨，笑着说：“你已经走到这里了，怎么算都不只有一把伞。”

那不是一个可以放进表格的答案。我把手机收起来，听他讲屋檐前那棵树，讲从前的招牌，讲对面面馆从早到晚散不去的蒸汽。

:::digest-stories 两则街边的小事
:::digest-story 多留的一把凳子
墙角始终靠着一把空凳子。晴天放工具，下雨就擦干净，留给没带伞的人。老人说，空着也不碍事。
:::

:::digest-story 没有结账的那一分钟
伞修好了，他又把每一道接缝撑开检查。我已经拿出手机，他却摆摆手，让我别着急。后来我常常想起的，恰好是这没有结账的一分钟。
:::
:::

## 雨停之前，先把路走慢一点

离开时，雨并没有停。旧伞重新撑在头顶，我第一次注意到，雨点落在不同伞面上，声音并不一样。

:::digest-epiphany 一点日常的回声
这不是一则劝人珍惜所有旧物的道理。有些东西确实该换掉，有些关系也需要告别。只是面对眼前还能认真修补的部分，我们可以不那么快地放手。
:::
