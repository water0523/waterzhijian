# 五篇写作体验样稿

这些是用于实际写作与排版检查的完整原创稿件，可以从编辑器“导入”选择 `.md` 文件。导入创建新文章，不替换已有稿件。新闻和人物稿中的场景明确为虚构，表中示意数据不能作为真实报道使用。

| 文件 | 建议主题 | 体验重点 |
| --- | --- | --- |
| 01 一杯温水的热量账本 | 深空靛蓝 / 松石青翠 | 公式、符号释义、推导、表格和脚注 |
| 02 修伞人把雨声留在门外 | 红枫暖刊 · 青年文摘风 | 长段落、半高荧光、引文与故事卡 |
| 03 社区工具图书馆的一周 | 深度新闻周刊 | 核心提要、数据表、问答、时间轴和档案 |
| 04 把一篇 Markdown 整理成可交付文章 | 科技前沿 / 理性蓝 | 代码、长命令、链接、上标引用与导出 |
| 05 从一根琴弦读一首夜曲 | 格物文史 | 诗歌、文学赏析、物理模型、嵌套组件 |

特殊主题需要在导入后选择相应主题，标签本身也可以继续修改。不要把所有组件都硬塞进同一篇文章；只使用适合内容的结构。
